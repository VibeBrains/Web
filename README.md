# vibeide.ru

Лендинг [VibeIDE](https://github.com/VibeBrains/VibeIDE) — статический сайт на Astro.
Цель страницы одна — скачивания: главная кнопка ведёт прямо на установщик последней сборки.
Русский — базовый язык по адресу `/`, английский — по адресу `/en/`.

Сайт сделан в одном стиле с [vibememory.ru](https://vibememory.ru): те же шрифты, сетка, кнопки и правила анимаций.
Акцент свой — две половины знака VibeIDE, бирюзовая и пурпурная.

## Сборка

```bash
bun install
bun run dev       # разработка, http://localhost:4321
bun run build     # статическая сборка в dist/
bun run preview   # просмотр собранного dist/
bun run check     # типы (astro check), сборка и гейт локализации (bun test)
```

Результат — папка `dist/`: HTML, CSS, JS и шрифты.
Внешний запрос у страницы один — к API релизов GitHub, чтобы показать сборки, вышедшие после выкладки.
Трекеров, аналитики и CDN нет.

## Что где

- `src/pages/` — две страницы: `index.astro` (ru) и `en/index.astro`
- `src/components/` — секции страницы, `Landing.astro` собирает их по порядку
- `src/components/Hero.astro` — 3D-окно IDE: слои расходятся в глубину и поворачиваются за курсором
- `src/components/Models.astro` — вращающаяся 3D-сфера с орбитой встроенных провайдеров
- `src/components/Autopilot.astro` — сцена хода агента: план, правки, тесты, лимит и продолжение
- `src/locales/ru.json`, `en.json` — все строки интерфейса, плоские ключи с точками
- `src/i18n/` — переводчик: подстановки `{name}`, откат на русскую строку
- `src/config/` — ссылки, провайдеры, конкуренты таблицы, разбор релизов GitHub
- `src/config/build.ts` — релизы на момент сборки: ссылки на скачивание работают и без скриптов
- `src/scripts/` — клиентский JS: появление при прокрутке, язык, копирование, живые релизы, 3D-наклон, сфера
- `src/styles/global.css` — палитра и шрифты, общие стили
- `tests/locales.test.ts` — гейт локализации

## Ссылки на сборки

Релизы у VibeIDE поплатформенные: исправление только под macOS делает `releases/latest` маковским.
Поэтому каждая кнопка ищет последнюю сборку своей платформы, а не верит `latest`.
Ссылки подставляются при сборке, а в браузере обновляются из API GitHub.
GitHub при сборке недоступен — кнопки ведут на страницу релизов, а скрипт подставит прямые ссылки.
После выпуска VibeIDE достаточно пересобрать и выложить сайт.

## Правила текстов

Одна строка каталога — одно предложение, в разметке строки выводятся отдельными блоками.
Точки в конце предложения нет, предложение не длиннее 160 символов.
Текст в разметке и в доступных именах (`aria-label`, `alt`, `title`) — только из каталога.
Названия продуктов, команды и код — данные из `src/config/`, гейт знает их поимённо.

## Анимации

CSS, SVG, canvas и немного JS.
Зацикленные сцены играют, только пока видны на экране.
3D-наклон за курсором — только при мыши, на сенсорных экранах сцены стоят в исходном ракурсе.
При `prefers-reduced-motion: reduce` анимаций нет: сцены показывают итоговое состояние.

## Выкладка

`./deploy.sh` собирает сайт и кладёт его на общий хост семейства в `/srv/vibeide/site/<коммит>`.
Ссылка `current` переключается одним переименованием: посетитель не видит полсайта.
Три последние сборки остаются для отката руками.
Выкладывается только закоммиченное.
Хост тот же, что у VibeMemory, SSH-алиас `vibememory`.
Caddy отдаёт `current` на `vibeide.ru`, а `www.vibeide.ru` перенаправляет на основной адрес.
Блок сайта живёт в репозитории VibeMemory, `infra/Caddyfile.tmpl`, и ставится его `infra/caddyApply.sh`.

## История хоста

До 07.10.2026 сайт жил на отдельном сервере под nginx и выкатывался из GitHub Actions по rsync.
На той сети TLS 1.3 на порту 443 резался, поэтому nginx отдавал только TLS 1.2.
На общем хосте Caddy работает с настройками по умолчанию.
Если проблема вернётся, ограничение ставится в блоке сайта: `tls { protocols tls1.2 tls1.2 }`.
